# Arsip dokumentasi

Isi folder ini merekam struktur dan pengaturan prototype sebelum penataan20Oktober2026. README_PROTOTYPE, README_OBSIDIAN dan PROJECT_INDEX_OBSIDIAN bukan petunjuk instalasi/kontrak aktif. Sebagian uraian path lama dipertahankan sebagai histori; tautan navigasi mengarah ke lokasi dokumen baru.

Konfigurasi Obsidian lama berada di obsidian-config/ dan tidak perlu digunakan untuk membaca proyek. Metadata prototype serta hasil pemeriksaan TypeScript lama berada di folder ini sebagai referensi historis, bukan hasil validasi setup Laravel saat ini.

Mulai dari [indeks dokumentasi aktif](../README.md), [panduan Eko](../EKO_PROJECT_GUIDE.md), dan [setup Laravel/React](../SETUP.md).
