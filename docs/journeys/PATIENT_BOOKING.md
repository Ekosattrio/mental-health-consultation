# Journey Pasien memesan dan menerima layanan
## Prasyarat
Login ACTIVE, profil pasien yang diakses, paket bookable dengan durasi positif.
## Langkah
1. Lihat kategori/paket/harga/promo setelah login.
2. Pilih sesuai batas kalender F05 dan interval setelah tiga jam kerja penuh yang cukup untuk durasi.
3. Isi profiling versi baru dan consent; draft tidak menahan slot.
4. Preview server harga final, DP minimum dan deadline min24jam/(awal sesi−2jam).
5. Submit; server membuat reservasi/tagihan atomik. Retry key sama tidak menggandakan booking. Pada Psikoterapi pertama, rangkaian administratif empat unit otomatis terbentuk bersama appointment/tagihan sesi1 saja; pasien tidak menunggu owner membuat rangkaian. Sesi berikutnya diatur Admin sesuai arahan praktisi/kesepakatan pasien. Jika rangkaian sudah ada, UI mengarahkan ke Admin, bukan mengulang pendaftaran rangkaian.
6. Bayar di luar aplikasi, unggah bukti lengkap <=deadline. Slot dilindungi, uang belum terverifikasi.
7. Jika bukti ditolak, baca alasan dan perbaiki sebelum correction deadline. SLA tidak reset.
8. Hadir offline atau mengikuti Google Meet untuk Telelayanan. Admin cek identitas/pembayaran dan catat check-in sesudah minimum DP. Pada Telelayanan, form booking mengonfirmasi nomor WA; setelah booking Admin memasukkan link Meet dan sistem mengirim otomatis lewat Baileys. Link/detail tersedia untuk pemilik berizin (F20), bukan check-in otomatis.
9. Terima layanan, bayar pelunasan/addendum jika ada, lihat receipt dan riwayat sendiri.
10. Asesmen dapat jadwal evaluasi berbeda dengan satu case/tagihan; psikoterapi per sesi. Hasil boleh offline.
11. Review setelah layanan eligible; unduh PDF sampai tujuh hari sejak penutupan layanan.
## Cabang
Slot konflik: pilih lagi, tidak ada sukses semu. Reschedule: submit sebelum H-2 atau sampai empat hari kalender setelah NO_SHOW, maksimal3 APPLIED. Waktu submit menentukan kelayakan. Perubahan dari klinik: pilih kembali, tidak memakai kuota.
Slot expired sudah dipesan orang lain: Admin mencari slot baru; tidak merebut slot. Tidak ada refund/credit otomatis.
## Hasil
Riwayat identitas, profiling, jadwal, invoice dan penerimaan tetap utuh. F03–F12,F15,F18.
